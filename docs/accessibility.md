# 접근성 점검

KWCAG 2.2 33개 검사항목을 자체 점검한 결과입니다. **공인 인증이 아니며, 실제 스크린 리더 확인은 아직 하지 않았습니다.**

- 항목 번호와 이름은 [비공식 정리본](https://a11ykr.github.io/kwcag22/)을 따랐습니다. 인용이나 인증에는 공식 문서로 확인해야 합니다.
- 5.3.2, 5.4.3, 6.1.2, 6.1.3, 6.4.2, 6.5.3, 7.2.2, 7.3.1, 7.3.4, 8.2.1은 정리본의 기준 문구를 확인했습니다. 나머지는 항목 이름과 일반적인 이해를 바탕으로 판단했습니다.

## 결과

방법: **E2E**는 프로덕션 빌드를 Chromium, Firefox, WebKit으로 검사하는 자동 검사, **axe**는 자동 규칙 검사, **코드**는 코드와 화면을 직접 확인한 것입니다.

| 5.1.1 대체 텍스트 | 충족 | axe, E2E | 포스터는 제목으로 대체 텍스트 제공. 배경 이미지는 장식이라 빈 `alt` |
| 5.2.1 자막 | 해당 없음 | 코드 | 실제 영상과 음성 없음. 재생 화면의 자막 버튼은 화면 상태만 바꿈. 실제 영상을 넣으면 다시 점검 필요 |

## 스크린 리더 직접 확인 목록

Chromium 접근성 트리로 이름과 구조는 확인했지만, 실제로 읽히는 방식과는 다를 수 있습니다. macOS에서는 VoiceOver(`Cmd+F5`)로 다음을 확인합니다.

1. 메인: 본문 바로가기, 제목 탐색, 대표 영화, 카드의 포스터·제목·표시가 자연스럽게 읽히는가
2. 화면 전환: 카드를 열면 새 본문부터 읽기 시작하는가
3. 리스트: 필터의 레이블과 도움말이 읽히고, 적용하면 결과 수가 안내되는가
4. 가입: 필수 여부와 도움말이 입력 칸과 함께 읽히고, 입력 오류는 해당 칸으로 초점이 옮겨 가 문구가 함께 읽히며, 가입 실패 안내는 초점 이동 없이 읽히는가
5. 결제: 가상 결제 안내와 결과 선택, 실패 안내가 읽히는가
6. 테마 전환: 버튼 이름이 전환할 모드(다크 모드, 라이트 모드)로 바뀌어 읽히는가
7. 포스터 줄: 줄 제목과 전체 보기, 이전·다음 버튼의 이름이 읽히는가
8. 플레이어: 재생 위치의 값이 시간으로 읽히고, 자막과 음소거의 눌림 상태가 읽히는가
9. 찜하기: 눌림 상태가 읽히는가
10. 탈퇴: 확인 창과 실패 안내가 읽히는가
11. 로딩: "불러오는 중" 안내가 읽히는가. 처음부터 내용이 있는 상태 영역은 스크린 리더에 따라 읽지 않을 수 있습니다
12. 공개 알림: 종의 이름에 새 소식 수가 읽히고, 펼침 상태가 읽히며, Esc로 닫으면 종으로 초점이 돌아오는가
13. 이어 보기 지우기: 작품 이름이 포함된 버튼 이름이 읽히고, 지운 뒤 본문으로 초점이 옮겨 가는가
14. 아이콘 버튼: 검색, 공개 알림, 테마 전환 버튼에 초점을 주면 이름이 읽히고 툴팁이 보이며, Esc로 닫히는가
15. 실패 안내: 찜하기·결제 등이 실패하면 초점이 버튼에 남은 채 안내가 읽히고, 화면 전체를 불러오지 못하면 그 안내가 읽히는가
